### 🛠️ Core Engineering Stack & Architecture
- **Frontend & SSG**: Astro, Vue 3 (`<script setup lang="ts">`), React 19, TypeScript, Tailwind CSS
- **Client-Side Compute**: Web Workers, WebAssembly (WASM / ONNX Runtime), W3C WebGPU, WebRTC P2P, HTML5 Canvas, Service Worker CacheStorage
- **Edge & Security**: Cloudflare Pages, TLS 1.3 / HSTS Preload, DNSSEC, strict Content Security Policy (CSP), Grade A+ SSL Labs
